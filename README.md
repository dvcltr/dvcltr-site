# dvcltr-site

Terminal-style school progress blog for dvcltr.com.

## Commands

```bash
npm run dev
npm run build
npm run preview
```

## Content

Weekly status posts live in:

```text
src/content/status/
```

Each post is Markdown with frontmatter:

```yaml
---
title: "Weekly Status: Month Day–Day, Year"
date: YYYY-MM-DD
course: "CYBR-508"
summary: "Short privacy-safe summary."
tags: ["Tag"]
draft: false
---
```
